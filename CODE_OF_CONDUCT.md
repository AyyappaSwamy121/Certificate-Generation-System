# Contributor Covenant Code of Conduct

Our project follows the Contributor Covenant Code of Conduct. By participating, you are expected to uphold this code. The full text can be found at https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Summary
- Be respectful and considerate.
- Do not harass or discriminate.
- Be collaborative and gracious in feedback.

Enforcement
If you are subject to or witness unacceptable behavior, please report it by opening an issue or contacting the maintainers at `maintainers@cscindia.org.in`.
