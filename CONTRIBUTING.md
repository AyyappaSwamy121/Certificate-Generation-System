# Contributing to Certificate Generation System

Thanks for your interest in contributing! We welcome contributions that improve documentation, fix bugs, add features, or improve tests and CI.

Please follow these guidelines to make the contribution process smooth:

1. Fork the repository and create a feature branch from `main`.
   - Branch naming: `feature/<short-description>` or `fix/<short-description>`.

2. Keep changes focused and small. One logical change per PR makes review easier.

3. Write tests for new features and bug fixes. Run the test suite locally before opening a PR:

```bash
pip install -r certificate_system/requirements.txt
python certificate_system/manage.py test
```

4. Follow the project's coding style:
   - Use `black` for formatting (optional but recommended).
   - Keep code readable and well-documented.

5. Update documentation where appropriate (README, docstrings, or templates).

6. Open a Pull Request with a clear title and description. Link relevant issues and include screenshots or logs if applicable.

7. Address reviewer feedback promptly and squash or rebase commits as requested.

Thanks — contributions keep this project healthy and useful!
